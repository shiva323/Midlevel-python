## 📖 درباره‌ی این دوره

این جزوه برای **نوجوانانی** نوشته شده است که با مقدمات پایتون (متغیر، `print` و انواع داده‌ی ساده) آشنا هستند و می‌خواهند قدم بعدی را بردارند. هر جلسه یک **نوت‌بوک Jupyter** است که می‌توان آن را خواند، اجرا کرد و تغییر داد.

در هر جلسه این بخش‌ها را می‌بینی:

| بخش | توضیح |
|:---|:---|
| 🎯 **اهداف** | در پایان جلسه چه چیزهایی یاد می‌گیری |
| 🔁 **مرور** | یک سؤال گرم‌کردن از جلسه‌ی قبل |
| 📘 **درس** | توضیح گام‌به‌گام با کدهای قابل اجرا |
| 🧠 💻 🔬 **مثال‌های میان‌رشته‌ای** | از EEG و نورون‌ها تا بیت و بایت و DNA |
| 💡 ⚠️ **نکته و خطای رایج** | ترفندها و دام‌هایی که باید بشناسی |
| 📜 **داستان تاریخ** | آدم‌هایی که علوم کامپیوتر و نظریه‌ی اطلاعات را ساختند |
| 🧩 **کوییز** | خروجی را حدس بزن، بعد جواب را ببین |
| ✏️ **تمرین‌ها** | از آسان تا چالشی، با پاسخ تاشو |
| 📝 **خلاصه** و 🏠 **تکلیف خانه** | برای تکرار و تثبیت |

## 🚀 چطور از نوت‌بوک‌ها استفاده کنم؟

**راه ۱: روی کامپیوتر خودت (پیشنهادی)**

1. [Anaconda](https://www.anaconda.com/download) را نصب کن، یا اگر پایتون داری، این دستور را بزن: `pip install notebook`
2. این مخزن را دانلود کن (دکمه‌ی سبز **Code** و سپس **Download ZIP**).
3. در پوشه‌ی دانلودشده دستور `jupyter notebook` را اجرا کن و جلسه‌ی ۱ را باز کن.

**راه ۲: Google Colab (بدون نصب)**

روی نشان **Open in Colab** در جدول بالا کلیک کن. همه‌ی جلسه‌ها در Colab کار می‌کنند، به جز بخش نقاشی جلسه‌ی ۱۱ (توضیح در پایین).

**راه ۳: فقط خواندن**

روی **باز کن** کلیک کن تا GitHub نوت‌بوک را همراه با خروجی‌ها نشان دهد. برای اجرای کدها به راه ۱ یا ۲ نیاز داری.

> ⚠️ **درباره‌ی turtle:** کتابخانه‌ی `turtle` یک پنجره‌ی گرافیکی جداگانه باز می‌کند؛ پس روی Jupyter کامپیوتر خودت، IDLE یا Thonny کار می‌کند، اما در Colab نه. در Colab می‌توانی کتابخانه‌ی جایگزین `ColabTurtle` را امتحان کنی.

> 💡 **درباره‌ی رنگ‌ها:** کادرهای رنگی و سربرگ‌های جلسه‌ها در Jupyter و Colab به شکل کامل نمایش داده می‌شوند. GitHub بعضی از سبک‌های رنگی را نشان نمی‌دهد، اما همه‌ی متن و ساختار سر جایش است.
