## 📖 درباره‌ی این دوره

در هر جلسه این بخش‌ها را می‌بینی:

| بخش | توضیح |
|:---|:---|
| 🎯 **اهداف** | در پایان جلسه چه چیزهایی یاد می‌گیری |
| 🔁 **مرور** | یک سؤال گرم‌کردن از جلسه‌ی قبل |
| 📘 **درس** | توضیح گام‌به‌گام با کدهای قابل اجرا |
| 🧠 💻 🔬 **مثال‌های میان‌رشته‌ای** | از EEG و نورون‌ها تا بیت و بایت و DNA |
| 💡 ⚠️ **نکته و خطای رایج** | ترفندها و دام‌هایی که باید بشناسی |
| 📜 **داستان تاریخ** | آدم‌هایی که علوم کامپیوتر و نظریه‌ی اطلاعات را ساختند |
| 🧩 **کوییز** | خروجی را حدس بزن، بعد جواب را ببین |
| ✏️ **تمرین‌ها** | از آسان تا چالشی، با پاسخ تاشو |
| 📝 **خلاصه** و 🏠 **تکلیف خانه** | برای تکرار و تثبیت |
